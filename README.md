# Direct Supply

Website for getdirectsupply.co.uk: verified UK schools find and book supply teachers directly.

- `index.html` – landing page
- `app.html`, `app.js` – the app (accounts, teachers, vacancies, inbox, admin)
- `styles.css` – shared styles
- `geo.js` – UK postcode district and town coordinates (CC0, from Gibbs/uk-postcodes)

Backend: Supabase project `direct-supply` (London). Database rules and Stripe functions live there.
Hosting: Netlify, publishing this repository with no build step.
